Add hover effects to your Gutenberg blocks easily with customizable color transitions.

== Description ==

Blocklayouts Hover Color Controls adds hover color settings to blocks in the block editor. You can set a hover text color, background color and border color, and choose how long the color change takes and which easing it uses.

Features:
* Easy-to-use hover controls in the block editor
* Smooth color transitions
* Works with blocks that support color settings (Paragraph, Heading, Button, etc.)
* Customizable transition timing (ease, ease-in-out, linear, etc.)
* No coding required

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/blocklayouts-hover-color-controls` directory, or install the plugin through the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. In the block editor, select a block that supports color settings.
4. Open the Styles tab in the block settings sidebar and use the Hover Text, Hover Background and Hover Border options in the Color panel.
5. Once a hover color is set, adjust the transition duration and timing function below it.

== Frequently Asked Questions ==

= Which blocks can I add hover effects to? =

You can add hover effects to any block that supports color settings.

= Can I customize the transition timing? =

Yes. After you set a hover color, you can change the transition duration (0 to 2000 ms) and the timing function (ease, linear, ease-in, ease-out, ease-in-out).
